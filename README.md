# Аят — обновлённая версия

Обновление интерфейса приложения «Аят» поверх исходной версии из `Hamat8606/Ayat`. Исходный репозиторий не изменяется.

## Что включено
- Тёмная тема по умолчанию и светлая тема-пергамент.
- Подсветка прочитанных арабских слов.
- Журнал завершённых аятов с датой, временем и оценкой распознавания.
- Переключатель озвучки русского перевода встроенным голосом браузера.
- Потоковое арабское чтение по сурам через CDN Al Quran Cloud; список аудио строится по встроенному порядку 6 236 аятов, без дополнительного API-запроса перед первым воспроизведением.
- Резервный аудио-домен и кэширование выбранной суры для офлайн-прослушивания.
- Ссылка на MP3-архив перевода смыслов Кулиева (записи доступны по сурам/частям, не синхронизированы с отдельными аятами приложения).
- Пауза распознавания при уходе со страницы, Wake Lock и PWA manifest/service worker.

## Публикация
В репозитории добавлен GitHub Actions workflow для GitHub Pages. Если Pages ещё не настроен, откройте **Settings → Pages** и выберите **GitHub Actions** в разделе Build and deployment. После этого сайт будет публиковаться при обновлениях ветки `main`.

## Проверки перед публикацией
Workflow проверяет JSON-манифест, обязательные HTML-элементы, дублирующиеся ID и синтаксис JavaScript через Node.js. После публикации он дополнительно запрашивает сайт, манифест и Service Worker и проверяет их содержимое.

## Важное примечание
Основные функции распознавания и перехода между аятами сохранены из исходного приложения. MP3-записи Кулиева доступны через внешний каталог IslamHouse, но не подключены как автоматическая озвучка каждого завершённого аята: найденные записи идут по сурам или частям и не имеют надёжной привязки к аятам. Озвучка перевода по завершении аята пока использует встроенную речь браузера. Арабское аудио суры можно потоково слушать и отдельно кэшировать для офлайн-доступа.
